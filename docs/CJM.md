# Customer journey (CJM)

Минимальное ветвление: **основной поток** — линейный; отклонения — короткие и явные.  
**Первая реализуемая волна (MVP v0.1):** [MVP.md](MVP.md) — **лендинг** + **арена с логом** по прямой ссылке. Ниже — **полный** продукт (ретро, фазы, арена-геймплей) как целевой сценарий.

---

## MVP v0.1 (группы + мультиплеер-лог)

**A — с лендинга**

1. Открыть сайт.  
2. **Создать группу** → сервер выдаёт **ключ** и **ссылку** вида `…/g/{KEY}` (или `/join/…` — [PROTOCOL.md](PROTOCOL.md)).  
3. Перейти по ссылке → **арена** (Phaser, lazy) без Phaser на лендинге.  
4. Ввести **отображаемое имя** в **модалке на арене** → **WebSocket** → в **логе** — присоединение.  

**B — гость по прямой ссылке**

1. Открыть **https://…/g/{KEY}** из чата.  
2. **Арена** → **имя** в модалке (см. [PROTOCOL](PROTOCOL.md)) → **WS** → **лог** (join / другие).  

**C — ввод кода вручную**

1. На **лендинге** ввести код группы.  
2. Переход на `/g/CODE` или `/join/CODE` — **та же** арена, **имя** на арене, затем WS ([PROTOCOL](PROTOCOL.md)).

## Полный продукт (после v0.1) — ориентир

### Сценарий A: лид (создатель сессии)

1. Открывает веб-приложение.  
2. Нажимает **«Создать ретро»** (или аналог).  
3. Выбирает **сценарий** (см. [SCENARIOS.md](SCENARIOS.md)).  
4. Получает **ключ** и/или **ссылку** с ключом.  
5. Делится с командой.  
6. Вводит **имя**, при необходимости выбирает **персонажа**.  
7. **Лобби** — ждёт участников.  
8. **Ведущий** запускает **арену/ретро**.  
9. **Этапы** ретро.  
10. **Финальное голосование** сценария.  

### Сценарий B: участник

1. **Ссылка** с ключом **или** сайт + код.  
2. **Имя** и **персонаж**.  
3. **Лобби** / ожидание.  
4. **Арена** по сигналу ведущего.  
5. Этапы, карточки; **параллельно** (в полной версии) — движение, мобы ([REQUIREMENTS](REQUIREMENTS.md)).  
6. **Финальное** голосование.  

## Короткие ветки (отклонения)

| Ситуация | Поведение |
|----------|-----------|
| **Неверный ключ** | Сообщение; повтор ввода (политика утечки существования кода — [NFR](NFR.md)). |
| **Сессия заполнена / закрыта** | Понятное сообщение. |
| **Передача ведущего** | (Полный продукт) панель у нового ведущего. |
| **Отключение сети** | [NFR](NFR.md), переподключение. |
