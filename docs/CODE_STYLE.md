# Стиль кода (на будущее; правила для агентов и людей)

Код ещё не введён; эти правила **активны** с первого коммита приложения. До появления **ESLint/Prettier** — ориентир **ниже** вручную.

## Общие принципы

- **TypeScript** предпочтительнее **JavaScript** для новой логики; избегать `any` без причины.
- **Одна зона ответственности** на модуль; не раздувать файлы **без** согласованного рефакторинга.
- **Секреты** — **никогда** в исходниках; только `process.env` / `import.meta.env` и документированные имена в `.env.example`.
- **Коммиты** — смысловое сообщение, одна тема на коммит где возможно.

## Имена

- **camelCase** для функций, переменных, методов.
- **PascalCase** для классов, React-компонентов, типов, enum имён.
- **UPPER_SNAKE** для **констант** уровня модуля, если **действительно** неизменяемы.
- Файлы: **PascalCase** для компонентов (если React/похоже); иначе **kebab-case** — **выбрать при первом пакете** и держать единообразно.
- **Монорепо:** клиент **только** в `apps/client/`, сервер **только** в `apps/server/`; не смешивать слои без веской причины.

## Форматирование (при подключении инструментов)

- **Prettier** — дефолтные настройки, `trailing comma: "es5"` (или as needed по TS) — **зафиксировать в `package.json`**.
- **ESLint** — рекомендованные пресеты + TypeScript; правила, конфликтующие с Prettier, **не** включать.

## Игровой слой (Phaser/аналоги)

- Разделять: **сцена / ввод** / **симуляция** (если тесты понадобятся) / **сеть (адаптер)**.
- **Магические числа** (скорости, тайл) — **константы** с именем или `config` объект.

## Go (`apps/server`, когда появится)

- `gofmt` и `golangci-lint` (или `staticcheck` — TBD) в **CI**; модуль — в `apps/server` (или `go.work` в корне — TBD).
- **Интерфейсы** — минимальные, осмысленные; **не** скрывать **ошибки** через `log.Fatal` в **HTTP-обработчиках** (кроме `main`/init, если оправдано).
- **Middleware** (request id, **структурированный** **лог**) — по мере **нужды**.

## Тесты

- **Unit (TypeScript):** при появлении Vitest/Jest — **чистые** функции (логика ретро, парсер сообщений). **E2E** — **см. **`docs/E2E.md` (Playwright, CJM, CI, когда **подключат**; до кода **—** **только** **документация**).

*Апдейт: `eslint`/`tsconfig` после `npm init`; `golangci` после `go mod init` в `apps/server`.*
