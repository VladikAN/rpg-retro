# Развёртывание

## Подход

- **docker-compose** в корне репозитория: `docker-compose.yml`.
- **Секреты и конфиг** — **только** через переменные окружения; **не** коммитить `.env`.
- Пример имён: **`/workspace/.env.example`**.

## Локальный запуск (когда появятся сервисы)

1. Скопировать `.env.example` → `.env` и задать значения.
2. `docker compose up --build` (или `up -d` для фона).
3. Открыть `http://localhost:${HTTP_PORT}` (порт — из `.env`).

*На момент инициализации в `docker-compose.yml` ещё **нет** полноценных `app`/`api` сервисов — файл — каркас; дополнять при появлении `Dockerfile` и образов.*
