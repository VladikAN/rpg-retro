# ADR 0002: Рантайм и язык сервера

## Статус

Принято (документация v1; детали реализации уточняются в коде).

## Контекст

Сервер должен: **CRUD/жизненный цикл сессий**, **валидация ключей**, **WebSocket-хаб**, раздача **статики** SPA, упаковка в **Docker**.

## Решение

- Сервер пишется на **Go** (Golang): один бинарник, конкурентность для WebSocket, типичный деплой в контейнере, отдача embed FS для фронтенда.

## Обоснование

- Предсказуемое потребление памяти и простой «один артефакт» в CI/CD.
- Официальные библиотеки и экосистема для HTTP/WebSocket без тяжёлого runtime.

## Риски

- Нет общих TypeScript-типов с клиентом — дублирование контрактов; митигация: **OpenAPI/JSON Schema** или **Buf/protobuf** (по выбору), ручная синхронизация, кодоген при росте API.

## Последствия

- Структура `server/` на Go; клиент в `client/` — TypeScript.
- Значимые изменения в роли бэкенда — через обновление этого ADR и [ARCHITECTURE.md](../ARCHITECTURE.md).
