# Сценарии ретро (контент)

Сценарий задаёт **лор**, **локацию**, **объект для сбора карточек** и **финальное голосование**. Создатель сессии выбирает сценарий при настройке. Тон — **лёгкий, шуточный**.

## Общие правила сценария

- **Локация** — визуальная обстановка (тронный зал, казармы, пещера дракона, трюм и т.д.); **ведущий** размещается в логичной для сцены точке (у трона, у дракона и т.д.).
- **Сбор карточек** — метафора: стол, **магический кубок**, **сундук**, другое согласованное с артом.
- **Карточки** бывают двух типов:
  - **Положительные** — что прошло хорошо, что помогло, победы;
  - **Негативные** — что мешало, что стоит улучшить, препятствия.
- Сценарий задаёт **шуточные подписи** к этим типам, чтобы участники писали в рамках метафоры.
- **Последний этап** — **анонимное голосование**:
  - **«Успех»** — участник считает ретро удачным: процесс + сформулированные action items.
  - **«Провал»** — участник не доволен; метафора — **без** оскорблений персон, только про процесс.
- Сценарий **не** блокирует **сайд-активности** (мобы, золото) — параллельно с этапами, где уместно.

## Сценарий 1: «Битва с драконом»

**Идея:** Команда дошла до финала и встретила **злого дракона**. Пока дракон **спит** в пещере, герои **устраивают ретро** прямо у него на пути — разбирают, как прошёл поход, чтобы победить дракона наверняка.

| Элемент | Описание |
|---------|----------|
| Локация | Пещера дракона; ведущий стоит рядом со **спящим** драконом (статичный/простой спрайт). |
| Сбор карточек | **Магический кубок** — участники «вкладывают» карточки в кубок поочерёдно. |
| Финал | Анонимное голосование: **«Разбудили дракона своим провалом»** vs **«Усыпили его магией командной работы»**. |

### Подписи карточек в UI

| Тип | Метафора в UI | Примеры реплик участников |
|-----|---------------|---------------------------|
| Положительные | «Зелья в сумке» / «Что было в нашем арсенале» | «Быстро договорились о приоритетах», «Ревью проходили за день» |
| Негативные | «Монстры на пути» / «Что нас замедлило» | «Задачи падали в спринт в последний момент», «Нет сезонного планирования» |

### Реплики в логе событий (Arena) — примеры

- `Иванов вошёл в пещеру дракона`
- `Петрова покинула отряд — дракон слышит её шаги`
- `[Ведущий] Кладём зелья в кубок... Дракон всё ещё спит`

### Финальное голосование — текст в UI

- ✅ **«Миссия выполнена — дракон не проснулся!»**
- ❌ **«Дракон проснулся... Попробуем ещё раз»**

## Сценарий 2: «Поиск сокровищ»

**Идея:** После долгого пути команда открыла **тайный тронный зал** с **огромным сундуком**, но **сундук закрыт**. Чтобы **открыть** его, команда проводит ретро — каждый голос и карточка «вставляют ключ».

| Элемент | Описание |
|---------|----------|
| Локация | **Тронный зал**; ведущий — у **трона** или рядом с запертым сундуком. |
| Сбор карточек | **Сундук** — карточки «закидывают» внутрь. |
| Финал | Голосование: **«Сундук открылся — сокровища ваши!»** vs **«Замок не поддался — вернёмся с новым планом»**. |

### Подписи карточек в UI

| Тип | Метафора в UI | Примеры реплик участников |
|-----|---------------|---------------------------|
| Положительные | «Золото в сундуке» / «Что уже лежит в кладовой» | «Новый CI сократил деплой в 3 раза», «Код-ревью стали конструктивнее» |
| Негативные | «Ловушки в зале» / «Что почти нас завалило» | «Слишком много встреч без результата», «Долги по документации» |

### Реплики в логе событий (Arena) — примеры

- `Иванов вошёл в тронный зал`
- `Петрова покинула зал — сундук теряет частицу магии`
- `[Ведущий] Вкладываем сокровища... Сундук дрожит`

### Финальное голосование — текст в UI

- ✅ **«Сундук открылся — сокровища ваши!»**
- ❌ **«Замок не поддался — приходите с лучшим планом»**

## Сценарий 3: «Морское путешествие»

**Идея:** Команда на **пиратском корабле** в поисках приключений. В открытом море самое время провести ретро — разобрать, попутный ли ветер и нет ли пробоин в трюме.

| Элемент | Описание |
|---------|----------|
| Локация | **Палуба корабля** (дневной свет) или **трюм** (тёмное освещение — на выбор артиста); ведущий — у **штурвала** или рядом с картой. |
| Сбор карточек | **Бочка** на палубе или **стол** в кают-компании — уточняется артом. |
| Финал | Голосование: **«Курс верный — земля впереди!»** vs **«Буря снесла мачту — разворачиваем»**. |

### Подписи карточек в UI

| Тип | Метафора в UI | Примеры реплик участников |
|-----|---------------|---------------------------|
| Положительные | «Попутный ветер» / «Что несло нас вперёд» | «Хорошая коммуникация внутри команды», «Успели до дедлайна» |
| Негативные | «Рифы и штормы» / «Что едва не потопило корабль» | «Неясные требования от заказчика», «Тест-среда ломалась каждый день» |

### Реплики в логе событий (Arena) — примеры

- `Иванов поднялся на борт`
- `Петрова прыгнула за борт — один моряк меньше`
- `[Ведущий] Бросаем карточки в бочку... Волны нарастают`

### Финальное голосование — текст в UI

- ✅ **«Курс верный — земля впереди!»**
- ❌ **«Буря снесла мачту — зовём лоцмана»**

## Персонажи (универсальные для всех сценариев)

Участник выбирает персонажа **один раз** при входе на арену (v0.2+). Персонажи не привязаны к конкретному сценарию.

| Персонаж | Способность | Визуал (примерный) |
|----------|-------------|---------------------|
| **Рыцарь** | Удар мечом — урон по одному | 32×32, броня, меч |
| **Маг** | Фаерболы — урон по области | 32×32, посох, мантия |
| **Разведчик** | Лук — дальняя атака | 32×32, лук, плащ |
| **Скелет** | *(NPC или playable — уточнить в v0.2)* | 32×32, кости |

Боевая механика (сайд-активности) и выбор персонажа — **вне v0.1**; список приведён для планирования арта.

## Возможные локации (пул)

- **Тронный зал** — ведущий у трона; мрачная торжественность.
- **Рыцарские казармы** — военный, деловой сет; строгая атмосфера.
- **Пещера дракона** — ведущий у спящего дракона; напряжение и юмор.
- **Палуба/трюм корабля** — морская романтика; два варианта освещения.

Связь «сценарий → локация» задаётся **конфигом** (см. [ARCHITECTURE.md](ARCHITECTURE.md) при появлении схемы данных).
