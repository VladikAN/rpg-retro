# Сценарии ретро (контент)

Сценарий задаёт **лор**, **локацию**, **объект для сбора карточек** и **финальное голосование**. Создатель сессии выбирает сценарий при настройке. Тон — **лёгкий, шуточный**.

## Общие правила сценария

- **Локация** — визуальная обстановка (тронный зал, казармы, пещера дракона, трюм и т.д.); **ведущий** размещается в логичной для сцены точке (у трона, у дракона и т.д.).
- **Сбор карточек** — метафора: стол, **магический кубок**, **сундук**, другое согласованное с артом.
- **Последний этап** — **анонимное голосование**:
  - **За** — участник считает ретро удачным: и сам процесс, и **сформулированные action items** (в рамках шуточной метафоры — «команда справилась с миссией сценария»).
  - **Против** — участник **не** доволен ходом ретро; метафора в UI может быть «миссия провалена» / «сундук не открылся» — **без** оскорблений персон, только про процесс.
- Сценарий **не** блокирует **сайд-активности** (мобы, золото) — параллельно с этапами, где уместно.

## Сценарий: «Битва с драконом»

**Идея:** Команда дошла до финала и встретила **злого дракона**. Пока дракон **спит** в пещере, герои **устраивают ретро** прямо у него на пути, о том как прошёл путь.

| Элемент | Описание |
|--------|----------|
| Локация | Пещера дракона; ведущий — рядом со **спящим** драконом (статичный/простой спрайт). |
| Сбор карточек | **Магический кубок** — участники «складывают» карточки в кубок поочерёдно. |
| Финал | Анонимное голосование: **победили ли мы** миссию (не разбудить дракона + хорошее ретро) или **нет** — шуточно. |

## Сценарий: «Поиск сокровищ»

**Идея:** После долгого пути открыли **тайный тронный зал** с **большим сундуком**, но **сундук закрыт**. Чтобы **открыть** его, команда проводит ретро.

| Элемент | Описание |
|--------|----------|
| Локация | **Тронный зал**; ведущий — у **трона** или у сундука. |
| Сбор карточек | **Сундук** (или стол у сундука) — карточки «закидывают» в сундук. |
| Финал | Голосование: **сундук открылся** (в шутку, положительный исход) / **замок не поддался** (отрицательный исход ретро) — метафора, не детерминизм. |

---

## Сценарий: «Морское путешествие»

**Идея:** Команда на **пиратском корабле** в поисках приключений; **в пути** решает провести ретро.

| Элемент | Описание |
|--------|----------|
| Локация | **Палуба/трюм** корабля; ведущий — у штурвала, карты, бочки. |
| Сбор карточек | Например **бочка** или **стол** в кают-компании; уточняется артом. |
| Финал | Голосование: **курс верный** / **буря сорвала планы** — в шутку про успех ретро. |

---

## Возможные локации (пул)

- **Тронный зал** — ведущий у трона.
- **Рыцарские казармы** — более «военный» сет.
- **Пещера дракона** — ведущий у спящего дракона.

Связь «сценарий → локация» задаётся **конфигом** (см. [ARCHITECTURE.md](ARCHITECTURE.md) при появлении схемы данных).
