## Чеклист DoD (MVP v0.1)

**Функциональность:**
- [ ] **Два браузера:** создать группу с лендинга → скопировать ссылку `/g/{CODE}`
- [ ] Второй браузер открывает ссылку → вводит имя → в логе **оба** `player_joined`
- [ ] Закрыть вкладку одного → в логе второго `player_left` (или таймаут)

**Ops / сборка:**
- [ ] `docker compose up --build` → сервер поднимается на порту из `.env` (по умолчанию 8080)
- [ ] Статика клиента встроена в Go-образ (embed FS); отдельного nginx нет
- [ ] `GET /health` → 200 (пинг CI)

**Безопасность:**
- [ ] Нет секретов/паролей/токенов в коде и истории git
- [ ] `.env.example` актуален (все используемые переменные есть с placeholder-значениями)

**Тесты:**
- [ ] `go test ./...` — зелёный
- [ ] `npm run build` — без ошибок TS
- [ ] E2E smoke (`npm run test:e2e`) — зелёный

**CI (желательно):**
- [ ] GitHub Actions job: `go test` + E2E против `docker compose`
