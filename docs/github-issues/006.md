## Scope

### Сервер (Go)

1. **WebSocket-хаб** (`server/internal/hub/`):
   - `Hub` — хранит активные подключения, сгруппированные по `inviteCode` (map[string][]*Client).
   - `Client` — одно WS-подключение: goroutine чтения, goroutine записи, канал send.
   - `Broadcast(inviteCode, msg)` — рассылает JSON всем клиентам комнаты.

2. **Endpoint** `GET /ws/{inviteCode}` (HTTP Upgrade):
   - Читать `name` из query: `r.URL.Query().Get("name")`.
   - Валидация: имя 1–30 символов непустых; комната существует (`store.GetByCode`).
   - Ошибки → WS close code `4004` (room not found) или `4400` (name required), затем CloseMessage.
   - После upgrade: послать `room_state` (текущий список игроков) новому клиенту; broadcast `player_joined` остальным.
   - При disconnect: удалить клиента, broadcast `player_left`.

3. **Go WebSocket библиотека**: использовать `golang.org/x/net/websocket` или **`nhooyr.io/websocket`** (рекомендуется: modern API, нет gorilla legacy). Добавить в `go.mod`.

### JSON формат (см. PROTOCOL.md)

```json
// player_joined
{"type":"player_joined","payload":{"displayName":"Иванов","playerCount":2}}

// player_left
{"type":"player_left","payload":{"displayName":"Иванов","playerCount":1}}

// room_state (только новому клиенту)
{"type":"room_state","payload":{"players":["Иванов","Петрова"],"playerCount":2}}
```

### Клиент (TypeScript, `client/src/network/ws.ts`)

- Класс/функция `connectArena(inviteCode, displayName, onMessage)`.
- URL: `` `ws://${location.host}/ws/${inviteCode}?name=${encodeURIComponent(displayName)}` ``
- Открывать только после submit displayName на арене.
- При получении сообщения: парсить JSON, вызывать `onMessage(event)`.
- При закрытии WS: логировать, при необходимости показывать UI ошибки.
- Модуль изолирован от Phaser-сцены; сцена вызывает его как callback-API.
