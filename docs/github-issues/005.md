## Scope

### Сервер (Go) — уже частично реализовано
`GET /`, `GET /g/*`, `GET /join/*` → один `index.html` (SPA fallthrough).
Проверить, что `server/main.go` обрабатывает эти пути; поправить при необходимости.

### Клиент (TypeScript, `client/src/`)

**1. История-роутер** (без сторонних библиотек):
- Читать `window.location.pathname` при загрузке.
- `/` → рендерить лендинг.
- `/g/{code}` или `/join/{code}` → парсить `code` из pathname, передавать в ArenaPage.
- Не использовать тяжёлый router-фреймворк; достаточно функции `resolveRoute()`.

**2. Лендинг (`/`)**:
- Кнопка **«Создать группу»**: `POST /api/v1/rooms` → получить `inviteCode` → `history.pushState` на `/g/{inviteCode}` → показать ArenaPage с этим кодом.
- Поле ввода + кнопка **«Подключиться»**: взять введённый код → `history.pushState` на `/g/{code}`.
- Никакого Phaser на лендинге. Простая HTML-разметка + минимальный CSS.
- Показать скопированную ссылку после создания комнаты (кнопка «Скопировать ссылку»).

**3. Страница арены (`/g/*`, `/join/*`)**:
- Показывать `inviteCode` из URL.
- Phaser НЕ загружать сразу — только после того, как пользователь введёт имя (E4).
- Реализовать форму ввода displayName (модалку/overlay) — без Phaser (чистый DOM/CSS).
- Phaser — `dynamic import('phaser')` в отдельном модуле `arena.ts`, который вызывается после submit имени (E4 подключит сцену, здесь достаточно заглушки).

**Структура файлов (примерная):**
```
client/src/
  main.ts          // точка входа, вызов router
  router.ts        // resolveRoute(), render landing / arena
  pages/
    landing.ts     // DOM лендинга, POST /api/v1/rooms
    arena.ts       // DOM арены, форма имени, lazy import phaser (E4)
  network/
    api.ts         // createRoom(): fetch POST /api/v1/rooms
```

## DoD тикета
- [ ] `/` открывает лендинг без ошибок в консоли
- [ ] «Создать группу» → редирект на `/g/{code}` в браузере
- [ ] Ввод кода + «Подключиться» → редирект на `/g/{code}`
- [ ] Прямой переход `/g/ABC` показывает страницу арены (не 404)
- [ ] Phaser НЕ загружается на `/` (проверить Network в DevTools)
- [ ] `npm run build` — без ошибок TS
