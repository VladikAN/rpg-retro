## Scope

### Клиент: Phaser сцена `ArenaScene`

**Lazy load** (в `client/src/pages/arena.ts`):
```ts
const Phaser = await import('phaser');
const game = new Phaser.Game({ ... scene: [ArenaScene] });
```
Вызвать только после submit имени пользователя.

**Конфиг игры:**
```ts
{
  type: Phaser.AUTO,
  width: 800,
  height: 600,
  backgroundColor: '#1a1a2e',
  parent: 'game-container',   // div в DOM
  scene: [ArenaScene],
}
```

**`ArenaScene` (`client/src/scenes/ArenaScene.ts`):**

- `create()`:
  - Подключить WS через `connectArena(inviteCode, displayName, this.onWsMessage.bind(this))`.
  - Создать массив строк `logLines: string[]`.
  - Создать Phaser.GameObjects.Text для каждой строки (или один `Text` с `\n`-join).
  - Показать приветственную строку: `[HH:MM] Добро пожаловать, {name}!`

- `onWsMessage(event)`:
  - `player_joined` → добавить строку `[HH:MM] {displayName} вошёл в комнату`.
  - `player_left` → добавить строку `[HH:MM] {displayName} покинул комнату`.
  - `room_state` → показать `[HH:MM] В комнате: {players.join(', ')}`.
  - Новые строки добавляются **снизу**; старые строки не удаляются (максимум 50 — обрезать сверху).

**Рендер лога:**
- Использовать `Phaser.GameObjects.Text` с `wordWrap`.
- Шрифт: моноширинный или pixel-style, размер 14px, цвет `#e0e0e0`.
- Фон лога: тёмный прямоугольник `Graphics`, альфа 0.7, внизу экрана (y = 300, height = 270).
- Лог занимает нижнюю половину экрана; верхняя — будущая арена/карта (пока пусто или плейсхолдер).

**Форма ввода имени** (DOM-overlay, до Phaser):
- Модалка: тёмный backdrop + `<input>` + `<button>Войти</button>`.
- Стили: inline CSS или отдельный класс. Центрировать по экрану.
- После submit: скрыть модалку, вызвать lazy import Phaser, создать Game.
- Если имя пустое — показать `border: 1px solid red` на input, не пускать дальше.
